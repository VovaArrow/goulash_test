# Запуск Goulash в CodeSandbox

Нужен Python Devbox (облачная VM), а также вход в аккаунт CodeSandbox.
Browser Sandbox для HTML/React не запускает этот Python-сервер.

## Перенос файлов

1. Создайте Python Devbox через https://codesandbox.io/templates.
2. Распакуйте `goulash-codesandbox.zip` на компьютере и перенесите содержимое
   в корень Devbox, включая скрытые `.codesandbox` и `.devcontainer`.
   Не добавляйте лишнюю вложенную папку вокруг `app`, `static` и `scripts`.
3. При необходимости пересоберите окружение с Python 3.12 по devcontainer.json.
   Задача `Goulash demo` устанавливает зависимости через setupTasks и запускает сервер.

Если задачи не подхватились после загрузки, выполните в терминале Devbox:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_codesandbox.py
```

## Публичная ссылка

Откройте Preview порта **8000** и скопируйте его внешний HTTPS-адрес.
Дайте посетителям доступ к preview в настройках CodeSandbox.
При необходимости откройте ссылку в отдельной вкладке: приложение ограничивает
встраивание в сторонние iframe заголовком X-Frame-Options.

При наличии `CODESANDBOX_HOST` скрипт автоматически определяет публичный Origin.
Если переменная отсутствует или адрес Preview другой, задайте переменную окружения
`GOULASH_PUBLIC_ORIGIN` равной точному HTTPS-адресу Preview без пути, затем
перезапустите задачу. Иначе защита Origin может отклонять отправку запросов.

## Данные и ограничения

Архив содержит только код, статические ресурсы и настройки. Локальная база,
сессии посетителей, токены и история Git не включены. Демо-база создаётся на VM;
каждый посетитель получает свою сессию. Реальные компании и ссылки на источники
включены в JSON проекта.

Проверка после запуска: поиск, четыре стартовые подборки, пять карточек во вкладке
«Реальный пример», сохранение выбора и сравнение. Сам контейнер и доступность
облачной ссылки должны быть проверены после импорта в аккаунт.

CodeSandbox использует лимиты VM на бесплатном плане и может останавливать
окружение. Актуальные условия: https://codesandbox.io/pricing.
