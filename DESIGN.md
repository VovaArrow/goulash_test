# Design

Визуальная система из static/styles.css, обновлена по референсу пользователя 22.10.2026: светлое поле и крупные тёмные блоки в стилистике Goulash.Tech.

- Светлый фон с лёгким бирюзовым оттенком (OKLCH), тёмный текст и приглушённые границы. На светлом фоне текстовые акценты имеют более глубокий бирюзовый цвет для читаемости.
- Тёмные шапка, главный поисковый блок, карточки поставщиков, карта и диалоги. Светлая форма поиска внутри главного блока.
- Тёмные поверхности: #1a1a1a, #202020, #262626.
- Текст: #f2f2f2, вторичный #c8c8c8, приглушённый #9a9a9a.
- Акцент: #21ffff. Статусы: #3ddc97, #ffc24b, #ff5c5c с текстовыми пояснениями.
- Onest с системным fallback, основной текст 14px/1.5.
- Для интерфейса используется локальный variable Onest с кириллицей: `static/fonts/onest-variable.woff2`, источник Google Fonts, лицензия `static/fonts/OFL-Onest.txt`. Внешние запросы Google Fonts не требуются, применяется `font-display: swap`.
- Радиусы 14px и 9px; белые основные кнопки, циан для ключевого действия.
- На широком экране фильтры, список и карта; на мобильном по умолчанию список.
- Нативные dialog, стандартные поля, focus-visible; данные пользователя выводятся текстом.

Логотип: исходный SVG из шапки https://goulash.tech/, без изменения геометрии (#00FFFF / #040406). Надпись: оригинальный Onest Medium из https://goulash.tech/wp-content/themes/goulash-theme/assets/fonts/Onest-Medium.woff, локально в static/fonts/. Пропорции из ui-kit.css: знак 32px, надпись 24px, интервал 10px.

## Liquid glass (22.10.2026)

По прямому запросу пользователя весь интерфейс использует liquid glass: прозрачные слои, тонкие светлые грани, внутренние блики и мягкие тени. Главный блок и карточки имеют градиент #101d20 → #14333c → #176478. Светлое поле сохранено. Backdrop blur применяется к плавающим панелям и диалогам, без тяжёлых SVG-фильтров. Предусмотрены fallback без backdrop-filter и уменьшение прозрачности/движения по системным предпочтениям.

## Мои подборки

История представлена раскрывающимися строками потребностей. Внутри — критерии, отдельные кнопки сравнения поставщиков и предложений, строки компаний с двумя ценами и простой отметкой. Ответ редактируется встроенной формой. Используются светлые стеклянные поверхности, разделители строк и существующие модальные таблицы; длинной шкалы статусов нет.
